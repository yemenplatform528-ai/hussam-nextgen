# دستور منصة الحسام اليمنية — NextGen

## 1. الهوية
منصة الحسام اليمنية هي بنية تشغيل رقمية موحدة لخدمة الأفراد والمنشآت والأسواق والقطاعات والمؤسسات داخل اليمن، مع قابلية التوسع خارجها.

## 2. الطبقات
1. Sovereign Core: الهوية، المؤسسات، العضويات، الصلاحيات، السياسات، التدقيق، الأحداث، idempotency، المال، دورة الحياة، الإعدادات.
2. Shared Engines: المالية، المخزون، المبيعات، المشتريات، المدفوعات، اللوجستيات، الأصول، المشاريع، CRM، الوثائق، سير العمل والتقارير.
3. Vertical Domains: التجزئة والبقالات، العيادات، معامل الأسنان، الصناعة، الشركات، المساجد والمشاريع الخيرية، وغيرها.
4. Intelligence: AI orchestration، agents، التحليلات، HUS Compiler.
5. Clients: Web، Android، APIs، POS والتكاملات.

## 3. قاعدة المصدر الواحد
كل مفهوم تشغيلي مشترك له مالك واحد في Core أو Shared Engine. لا تعيد القطاعات تعريف المال أو المخزون أو الصلاحيات.

## 4. قاعدة المال
القطاع يولد حقيقة تجارية؛ Finance Engine هو صاحب الحقيقة المحاسبية.

## 5. قاعدة المخزون
الحركة هي المصدر؛ الرصيد نتيجة/عرض مشتق. لا تعديل مباشر لرصيد المخزون من قطاع.

## 6. قاعدة الذكاء الاصطناعي
AI لا يصبح سلطة مالية أو تشغيلية بمجرد كونه AI. أي تغيير مؤثر يمر عبر عقد أمر deterministic وصلاحية وتدقيق.

## 7. قاعدة اليمن أولاً
التصميم يستوعب النقد، البيع الآجل، المحافظ، البنوك، التوزيع، الشحن بين المحافظات، ضعف الاتصال، وتعدد صور التسعير والعملات عند الحاجة، دون قفل المنصة على اليمن تقنيًا.
